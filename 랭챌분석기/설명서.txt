==============================================================
 랭챌 분석기  사용 설명서
==============================================================

랭킹챌린지에서 갱신할 때마다 상대 5명의 선발 + 타자 9명을 자동으로 읽고,
"내 선발 5명 x 상대 5명" 25가지 매치업 점수를 계산해서
가장 유리한 선발 배치를 추천합니다. 경기 결과는 엑셀에 쌓입니다.

이 프로그램은 내 PC에서만 돌아갑니다. (Claude 토큰을 쓰지 않아요)


--------------------------------------------------------------
 1. 처음 한 번만 하는 설치
--------------------------------------------------------------

[1-1] 파이썬 설치
  1) 인터넷에서 python.org 에 들어갑니다.
  2) 위쪽 메뉴 Downloads 에 마우스를 올리면 "Python 3.xx.x" 노란 버튼이 보여요. 누르면 설치 파일이 받아집니다.
  3) 받은 파일을 더블클릭하면 설치 창이 뜹니다.
     ★ 맨 아래 "Add python.exe to PATH" 칸을 꼭 체크하세요. ★
  4) "Install Now"를 누르고 끝날 때까지 기다립니다.

[1-2] 압축 풀기
  받은 zip 파일을 오른쪽 클릭 → "압축 풀기" → 원하는 곳(예: 바탕화면)에 풉니다.
  "랭챌분석기" 폴더가 생기면 됩니다.

[1-3] 설치.bat 실행
  "랭챌분석기" 폴더 안의 "설치.bat"을 더블클릭합니다.
  - 검은 창이 뜨고 글자가 쭉 올라갑니다. (필요한 부품을 받는 중이에요. 1~3분)
  - "Windows의 PC 보호" 파란 창이 뜨면 → "추가 정보" → "실행"을 누르세요.
  - 마지막에 Tesseract(글자 인식 프로그램)도 자동으로 설치를 시도합니다.
    "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 가 뜨면 "예"를 누르세요.
  - "DONE" 이 보이면 아무 키나 눌러 창을 닫습니다.

[1-4] Tesseract가 자동으로 안 깔렸을 때만 (직접 설치)
  1) 인터넷에서 "UB Mannheim tesseract" 를 검색해서 github 페이지(tesseract/wiki)에 들어갑니다.
  2) "tesseract-ocr-w64-setup-....exe" 파일을 받아서 실행합니다.
  3) 설치 경로는 바꾸지 말고 계속 "Next" → "Install".
     (언어 데이터는 프로그램 폴더에 이미 들어 있어서 추가로 고를 필요 없어요)


--------------------------------------------------------------
 2. LDPlayer 준비 (처음 한 번)
--------------------------------------------------------------

  이 프로그램은 LDPlayer(에뮬레이터) 안의 컴프야를 ADB라는 안드로이드 공식 도구로 조작합니다.
  PC 마우스를 쓰지 않아서, 도는 동안 다른 작업을 해도 되고 GameGuard에 막히지 않아요.

  1) LDPlayer 오른쪽 위 메뉴(≡) → 설정 → [고급 설정]
     - 해상도: "휴대폰" → 900 x 1600 (세로)  ★ 꼭 이 값으로 ★
     - 저장 후 LDPlayer 재시작
  2) LDPlayer 설정 → [기타 설정]
     - ADB 디버깅: "로컬 연결 열기"
  3) PC용 컴프야(크로스 플랫폼)는 같이 켜지 마세요. (같은 계정 동시 접속 불가)


--------------------------------------------------------------
 2-1. 실행하기
--------------------------------------------------------------

  1) LDPlayer를 켜고 컴프야를 실행해 둡니다.
  2) "실행.bat"을 더블클릭하면 검은 창과 함께 "랭챌 분석기" 창이 뜹니다.
     (검은 창은 닫지 마세요. 닫으면 프로그램도 꺼져요)
  3) 처음 버튼을 누르면 "[연결] 에뮬레이터 ... / 화면 900x1600" 줄이 나오면 정상이에요.

  ※ 작업 중에는 에뮬레이터 화면을 누르지 마세요. (LDPlayer 창은 가려져 있어도/최소화해도 돼요)
  ※ 언제든 멈추려면 키보드 F12 를 누르거나 [■ 중지] 버튼을 누르세요.

[화면 구성]
  - 왼쪽: 자주 쓰는 버튼이 쓰는 순서대로 있어요. (① 내 덱 읽기 → ② 상대 분석 → ③ 결과 기록, 아래쪽에 ④ 자동 진행 / 중지)
  - 오른쪽 탭
    · [추천 배치] 줄마다 추천 선발, 점수차, 예상 승률, 지금 배치를 표로 보여 줘요. 굵은 줄 = 바꿔야 하는 줄
                  (초록 = 내가 유리, 빨강 = 불리)
    · [상세표]    점수차 표, 예상 승률 표, 선발별 상세 점수
    · [내 덱]     읽어 둔 내 타자 9명 / 선발 5명과 점수·스킬
    · [진행 기록] 프로그램이 하는 일을 한 줄씩 보여 줘요. 버튼을 누르면 자동으로 이 탭이 열려요.
  - 위 메뉴: 가끔 쓰는 기능
    · 파일: 기록 엑셀 열기, 엑셀 수정 반영, 프로그램 폴더 열기, 설명서 열기
    · 학습: 학습 대기 확인, Claude로 일괄 학습, 학습 내용 점검, Claude 진단 메모 열기
    · 도구: 진단용 캡처, 진단 폴더 열기
    · 도움말: 버전 정보 / 업데이트, 설명서 열기
    · 설정: 클로드 코드 연동, 창을 항상 위에
  - 맨 아래 줄: 지금 하는 일, 연결된 에뮬레이터, Claude 연동 여부, 학습 대기 건수


--------------------------------------------------------------
 3. 사용 순서
--------------------------------------------------------------

[① 내 덱 읽기]  - 덱을 바꿨을 때만
  - 게임에서 [라인업] 화면을 열어 둡니다. 왼쪽 아래가 "랭킹 챌린지" 여야 해요.
  - 버튼을 누르면 지명타자 카드 → [상세 정보] 순서로 들어가서 타자 9명 → 선발 5명을 자동으로 읽습니다. (약 1분)
  - 다 읽으면 "타순 입력" 창이 뜹니다. 각 타자의 타순(1~9)을 고르고 [저장].
    다음부터는 같은 선수의 타순을 기억해서 미리 채워 줍니다.
  - 타순만 바꾸고 싶을 때는 [타순 입력] 버튼.

[② 상대 분석]  - 갱신할 때마다
  - 게임에서 랭킹 챌린지 [로비] 화면을 열어 둡니다. (PLAY BALL 버튼이 보이는 상태)
  - 버튼을 누르면 [순서 변경] → 줄마다 CLICK! → 상대 선발 카드 → 10명을 읽는 걸
    5번 반복합니다. (상대 5명, 약 2~3분)
  - 끝나면 아래 같은 결과가 나옵니다.

      점수차 표 (+면 내가 유리)   행 = 내 선발, 열 = 상대
      ▶ 추천 배치
      줄1 상대닉네임  상대선발 우투 OOO → 내 3선발 OOO +12.3  (지금: 1선발 +5.1)  ← 변경

  - 추천을 보고 게임의 [순서 변경]에서 직접 바꾼 뒤 [저장]하고 경기를 진행하세요.
    (배치를 바꾸는 건 프로그램이 하지 않습니다)

[③ 결과 기록]  - 경기가 끝난 뒤, 다음 갱신을 누르기 전에
  - 로비에 "승리 10:8" 같은 결과가 떠 있을 때 누릅니다.
  - 직전 분석과 짝지어서 경기마다 점수차와 결과를 엑셀에 기록합니다.
  - 깜빡하고 결과 기록 없이 [② 상대 분석]을 눌러도, 로비에 결과가 있으면 먼저 기록해 줍니다.
    ★ 단, 게임에서 [갱신]을 먼저 눌러 버리면 그 결과는 기록할 수 없어요. ★

  하루 흐름:  ① (덱 바꿨을 때) → ② → 배치 바꾸고 경기 → ③ → 게임에서 갱신 → ② → ...

[추천대로 배치]  - ② 상대 분석 뒤, 로비에서
  - 순서 변경 화면을 열어 추천대로 선발을 바꾸고 [저장]까지 해 줘요. (경기는 직접 시작)
  - 투수를 누르면 아래 창이 4·5번 줄을 가려서, 두 번째로 누르는 투수는 항상 1~3번 줄로 골라 바꿔요.

[④ 자동 진행]  - 로비 화면에서
  - 상대 분석 → 추천대로 배치 → [연속 경기] → 결과 기록 → 갱신 을 반복해요.
  - 갱신 범위
    · 포인트 갱신까지: 무료 → 포인트 갱신을 쓰다가, 다음 갱신이 스타로 바뀌면 그때의 5경기는 치르지 않고 남겨 두고 멈춰요.
      (다음 날 00시 레이팅을 낮게 유지해서 유리한 상대를 받기 위해)
    · 스타 갱신까지: 정한 횟수만큼 스타 갱신도 써요. 다 쓰면 마찬가지로 마지막 5경기는 남겨 두고 멈춰요.
    · 갱신 버튼이 회색 "금일 갱신 완료"로 바뀌면 오늘은 더 갱신할 수 없으니, 그때의 5경기도 남겨 두고 멈춰요.
  - 마감 시각(기본 23:59)까지 12분보다 적게 남으면 새 바퀴를 시작하지 않아요.
  - 연속 경기가 끝나면 결과 창의 [확인]을 누르고, 로비가 안 나오면(승급 화면 등) 화면 가운데를 한 번 눌러요.
  - 모르는 화면이 나오면 그 화면을 진단 폴더에 저장하고 멈춰요. [클로드 코드 연동]이 켜져 있으면 Claude에게 먼저 물어봐요.
  - 누르지 않는 것: 구매, 정한 횟수 밖의 스타 갱신, [연속 경기 종료]
  - 처음에는 "최대 바퀴 수"를 1로 두고 한 바퀴만 지켜보세요.
  - 오늘 프로그램이 쓴 갱신 횟수는 기록데이터\auto_state.json 에 남아요. (프로그램 밖에서 직접 갱신한 건 세지 않아요)


--------------------------------------------------------------
 4. 기록 파일 (랭챌기록.xlsx)
--------------------------------------------------------------

  위 메뉴 [파일] → [기록 엑셀 열기]로 엽니다.
  - 매치기록 : 한 줄 = 한 경기. 내/상대 타선점수, 선발점수, 점수차, 팀 OVR, 결과, 스코어.
  - 선수기록 : 경기마다 양 팀 10명씩의 원본값(스탯, 잠재, 스킬과 스킬 레벨)과 매치업 점수.
  - 분석기록 : 분석 때 계산한 5x5 표.
  - 내 덱    : 마지막으로 읽은 내 덱.

  ※ 이름/결과/스코어/스탯 등이 잘못 들어갔으면 엑셀에서 직접 고치고 [저장]한 뒤, 위 메뉴 [파일] → [엑셀 수정 반영]을 누르세요.
     - 고친 엑셀 파일을 고르면 원본 기록(기록데이터 폴더)에 반영돼요. 다른 이름으로 저장한 파일도 고를 수 있어요.
     - 스탯/스킬/잠재/좌우를 고친 경기는 점수와 점수차가 자동으로 다시 계산돼요. (점수 칸은 직접 고치지 않아도 돼요)
     - [내 덱] 시트를 고치면 다음 분석부터 고친 값으로 계산해요.
     - 반영 전 원본은 기록데이터\백업_날짜시각 폴더에 남아요.
     - [엑셀 수정 반영]을 누르지 않고 다음 기록을 하면, 엑셀이 원본 기록으로 다시 만들어지면서 고친 내용이 사라져요.
  ※ 엑셀을 열어 둔 채로 기록하면 엑셀 저장만 건너뜁니다. (기록은 "기록데이터" 폴더에 안전하게 남고,
     엑셀을 닫은 뒤 다음 기록 때 함께 저장돼요)
  ※ 나중에 분석을 맡기실 때는 "랭챌기록.xlsx" 파일 하나만 보내 주시면 됩니다.


--------------------------------------------------------------
 5. 학습 대기 확인
--------------------------------------------------------------

  처음 보는 숫자 모양(예: 아직 본 적 없는 스킬 레벨 9, 10)이나 확실하지 않은 값이 나오면
  프로그램이 그 그림을 "학습대기" 폴더에 모아 둡니다.
  위 메뉴 [학습] → [학습 대기 확인 (n건)]을 누르면 그림이 하나씩 나오고, 정답을 적고 Enter 를 누르면
  다음부터 그 모양을 정확히 읽습니다. 숫자가 쌓였을 때 가끔 눌러 주세요.
  Claude Code를 깔아 두었다면 [Claude로 일괄 학습]으로 한 번에 끝낼 수 있어요. (8번 참고)


--------------------------------------------------------------
 6. 문제가 생겼을 때
--------------------------------------------------------------

  - "에뮬레이터에 연결하지 못했어요" → LDPlayer가 켜져 있는지, ADB 디버깅이 "로컬 연결 열기"인지 확인.
  - "adb.exe를 찾지 못했어요" → LDPlayer 설치 폴더(예: C:\LDPlayer\LDPlayer9) 안의 adb.exe 전체 경로를
    app\settings_default.json 의 "adb_경로" 에 적어 주세요. 예) "adb_경로": "C:\\LDPlayer\\LDPlayer9\\adb.exe"
  - "화면 비율이 달라요" / "가로 화면이에요" → LDPlayer 해상도를 휴대폰 900x1600(세로)로.
  - 에뮬레이터를 여러 개 켜 두면 첫 번째 것에 연결돼요. 하나만 켜 두는 게 안전해요.
  - 상대 분석 중 한 상대에서 문제가 생기면 → 그 순간 화면이 "진단" 폴더에 자동 저장되고,
    로비로 돌아가서 그 상대를 한 번 더 읽어요. 두 번 다 실패하면 그 상대만 빼고 나머지로 추천합니다.
    (빠진 줄은 결과 창에 "줄[3] 상대는 못 읽어서 빠졌어요"처럼 나와요)
  - 중간에 멈춤 / 화면이 안 넘어감 → "진단" 폴더의 그림(자동 저장 또는 위 메뉴 [도구] → [진단용 캡처])과
    프로그램 창의 빨간 글씨를 캡처해서 보내 주시면 고쳐 드릴게요.
  - 점수 계산 숫자를 바꾸고 싶을 때 → app\settings_default.json 을 메모장으로 열어서 바꿉니다.
    (예: 타순별 타석수, 선발 담당 비율 0.7778 = 7/9 등)


--------------------------------------------------------------
 7. 계산 방식 요약
--------------------------------------------------------------

  타자 보정 = 파워 + 정확x0.85 + 선구x0.4 + 인내x0.15 + 잠재(풀스윙, 클러치, 각성잠재)
              + 발사각 보너스 + 스킬 점수
  투수 보정 = 구위x1.35 + 변화x1.05 + 잠재(장타억제력, 침착성, 각성잠재) + 좌완 1점 + 스킬 점수

  스킬 점수는 갤러리 스킬점수표(2026.08.14)를 쓰되, 아래 스킬은 이번 상대 조건으로 다시 계산합니다.
  - 좌우: 우완/좌완킬러, 우타/좌타킬러, 좌승사자, 좌타해결사, 스위치히터 (양타는 투수 반대 타석)
  - 홈/원정: 저니맨, 홈어드밴티지 (내 팀은 항상 원정, 상대는 홈)
  - OVR/별: 난세의 영웅(팀 OVR = 타자 9명 + 선발), 패기, 도전정신 (1:1 상대 기준)
  - 타순: 리드오프, 컨택트히터, 선봉장, 핵타선, 빈틈없는타선, 공포의하위타선, 수비안정성
  - 선봉장: 내 주루 > 상대 포수 수비면 발동 / 5툴플레이어: (주루+수비) x 레벨별 %
  - 선발이 던지는 7이닝은 실제 상대, 나머지 2이닝은 점수표 평균값
  타선 점수 = 타순별 타석 수(1번 4.65 ~ 9번 3.85)로 가중한 평균
  경기 점수차 = (내 타선 + 내 선발) - (상대 타선 + 상대 선발)
  예상 승률 = 1 / (1 + e^-(기준점 + 기울기 x 점수차))  — 둘 다 기록된 경기로 자동으로 다시 맞춤
        · 기울기: 처음 값 0.024 = 10점당 약 6%p. 기록이 적을 땐 처음 값 쪽으로 끌어당겨요.
        · 기준점: 점수차 0일 때 승률. 50%에 묶어 두지 않고 기록대로 맞춰요 (기록상 점수차 0에서도 50%보다 높게 이김)
  추천 = 120가지 배치 중 "기대 승점(승리 7점 x 승률 + 무승부 2점 x 무승부 확률)" 합이 가장 큰 배치
        → 이미 크게 이기는 경기보다 팽팽한 경기에 강한 선발을 넣어요
  OVR = 6개 스탯 평균(소수점 버림). 카드 OVR 숫자를 확실히 읽었는데 이 값과 다르면 스탯을 잘못 읽은 것으로 보고
        "확인 필요(스탯검산)"로 표시해요 (연동 중이면 Claude가 그 카드 스탯을 다시 확인)
  OVR 기준 스킬(난세/패기/도전정신)은 이 OVR로 판정해요

  아직 넣지 않은 것: 핫/콜존, 국가대표 에이스(국에), 불펜

--------------------------------------------------------------
 8. Claude Code 연동 (선택)
--------------------------------------------------------------

  PC에 Claude Code를 깔아 두면, 프로그램이 막히는 곳에서 Claude가 화면을 직접 보고 도와줍니다.
  ※ Claude 유료 구독(Pro 또는 Max)이 필요하고, 쓸 때마다 구독 사용량이 조금씩 들어요.
  ※ 이 기능은 Claude Code 프로그램을 쓰는 것이고, 지금 대화하는 Claude 앱과는 따로예요.

[8-1] Claude Code 설치 (처음 한 번)
  1) 키보드에서 윈도우 키를 누르고 "powershell" 이라고 쳐서 [Windows PowerShell]을 엽니다.
     (파란/검은 창. 관리자 권한은 필요 없어요)
  2) 아래 한 줄을 그대로 복사해서 창에 붙여 넣고(마우스 오른쪽 클릭) Enter:
        irm https://claude.ai/install.ps1 | iex
  3) 끝나면 그 창을 닫고, PowerShell을 새로 엽니다.
  4) claude --version 을 치고 Enter → "2.x.x (Claude Code)" 같은 버전 번호가 나오면 설치 성공.
     "인식되지 않습니다"가 나오면 PC를 한 번 재시작하고 다시 해 보세요.

[8-2] 로그인 (처음 한 번)
  1) PowerShell에서 claude 를 치고 Enter.
  2) 처음 묻는 것들(글자색 테마 등)은 Enter로 넘어가고, 로그인 방법은 Claude 계정(구독) 쪽을 고릅니다.
  3) 브라우저가 열리면 지금 쓰는 Claude 계정으로 로그인 → [승인].
  4) 창에 입력 칸이 나오면 로그인 완료. /exit 를 치고 Enter 로 닫습니다.

[8-3] 랭챌 분석기에서 켜기
  - 위 메뉴 [설정] → [클로드 코드 연동]을 체크합니다. "응답 확인 OK" 가 나오면 연결된 거예요.
  - 연동을 켜 두면:
    · 확인이 필요한 카드(확실하지 않은 스탯·발사각·스킬·잠재력·좌우)가 나오면 그 카드 화면에서 바로
      Claude가 화면을 보고 값을 바로잡은 뒤 다음 선수로 넘어가요. (카드 하나에 10~20초 정도 더 걸려요)
      결과 창에 "✓ Claude 확인 …" 과 "[Claude 진단] …" 이 나와요.
    · Claude가 확인한 값으로 그 카드에서 헷갈렸던 숫자 그림을 자동으로 학습해요. (카드 종류는 지금 점수에 거의 영향이 없어 확인 대상에서 뺐어요) (학습대기에 안 쌓여요)
    · 상대를 읽다가 화면이 막히면 Claude가 지금 화면이 뭔지 보고 어디를 눌러야 로비로 돌아가는지 알려 주고,
      프로그램이 그곳을 눌러요. (경기 시작, 갱신, 구매, 저장 같은 버튼은 누르지 않게 해 두었어요)
    · 작업이 멈추면 Claude가 막힌 이유와 해결 방법을 알려 줘요.
  - Claude가 확인한 내용과 "왜 틀렸을 것 같은지" 의견은 전부 위 메뉴 [학습] → [Claude 진단 메모 열기]로 메모장에서 볼 수 있어요.
    (파일: 진단\Claude_진단메모.txt, 그때 화면: 진단\Claude_화면 폴더)
    프로그램을 고쳐 달라고 할 때 이 메모 파일을 보내 주시면 원인을 바로 찾을 수 있어요.
  - 카드마다 기다리는 게 답답하면 app\settings_default.json 의 "claude_확인방식" 을 "한꺼번에" 로 바꾸세요.
    (상대를 다 읽은 뒤 한 번에 확인해서 더 빨라요)
  - 연동은 프로그램을 끄면 풀려요. 다음에 켤 때 다시 체크하세요.

[8-4] Claude로 일괄 학습
  - 위 메뉴 [학습] → [Claude로 일괄 학습](또는 "클로드학습.bat")을 누르면 학습대기 그림 전부를 Claude가 보고 정답을 붙여요.
  - 확인 창이 뜨면 훑어보고 틀린 칸만 고친 뒤 [모두 저장]. 비운 칸은 학습대기에 그대로 남아요.
  - 연동 체크를 안 해도 이 버튼은 쓸 수 있어요. (Claude Code 설치와 로그인은 필요)

[8-5] 학습 내용 점검
  - 예전에 [학습 대기 확인]에서 정답을 잘못 넣었을까 봐 걱정될 때 누릅니다. (클로드학습.bat 에도 있어요)
  - 지금까지 학습된 그림 전부를 Claude가 정답을 모르는 상태로 직접 읽고, 저장된 정답과 다른 것만 보여 줘요.
  - 줄마다 [고치기](입력칸의 값으로) / [지우기] / [그대로 두기]를 고르고 [적용]. Claude가 틀린 것 같으면 그대로 두기.

  ※ Claude Code를 다른 위치에 깔았거나 못 찾는다고 나오면 app\settings_default.json 의
     "claude_경로" 에 claude.exe 전체 경로를 적어 주세요. 예) "C:\\Users\\user\\.local\\bin\\claude.exe"


--------------------------------------------------------------
 9. 자동 업데이트 / 매주 기록 보내기
--------------------------------------------------------------

[9-1] 자동 업데이트
  - "실행.bat"으로 켤 때마다 새 버전이 있는지 확인해요. (1초 정도)
    새 버전이 있으면 묻지 않고 바로 받아서 바꾼 뒤 켜져요. 검은 창에 "업데이트 완료"가 나오고,
    프로그램 [진행 기록] 탭에 무엇이 바뀌었는지 나와요. 지금 버전은 창 제목과 맨 아래 오른쪽(v1.0.2 ⓘ)에 보여요.
  - 바꾸지 않는 것: 기록데이터, 랭챌기록.xlsx, 설정.json, 진단, 학습대기, .bat 파일
    · 학습 그림은 덮어쓰지 않고 새 그림만 추가해요. (내가 학습시킨 그림은 그대로)
    · 이름 고침표는 합쳐요. (내가 넣은 고침이 우선)
  - 바꾸기 전 버전은 "업데이트백업" 폴더에 최근 2개까지 남아요.
    새 버전이 켜지다 멈추면 다음에 켤 때 이전 버전으로 자동으로 되돌려요.
  - 인터넷이 안 되면 확인을 건너뛰고 지금 버전으로 켜져요.
  - 위 메뉴 [도움말] → [버전 정보 / 업데이트] (또는 아래 오른쪽 버전 글자 클릭):
    지금 버전, 최신 버전, 업데이트 기록을 보여 줘요. 새 버전이 있으면 [지금 업데이트] → [다시 켜기].
    예전 실행.bat(자동 업데이트가 안 되는 것)으로 켜져 있으면 빨간 글씨로 알려 주고 [실행.bat 새로 만들기]가 보여요.
  - 자동 업데이트를 끄려면 프로그램 폴더의 설정.json 에 "자동_업데이트": false 를 적어 주세요.
  - 새 버전이 올라오는 곳: https://github.com/wnsgur2791-hy/RangchaelHelper

[9-2] 매주 경기 기록 보내기
  - 처음 켤 때 한 번 보낼지 물어봐요. 위 메뉴 [설정] → [매주 경기 기록 보내기]로 언제든 끄고 켤 수 있어요.
  - 시즌이 끝난(월요일 0시가 지난) 주의 매치 기록과 선수 카드 정보를 개발자에게 보내요.
    한 주에 한 번만 보내고, 프로그램을 켜 둔 동안 6시간마다 보낼 게 있는지 확인해요.
  - 상대 닉네임은 지우고 보내요. 내 닉네임과 게임 계정 정보는 원래 기록에 없어요.
    보내는 사람은 무작위 번호(예: 3fa9c2d1)로만 구분돼요.
  - 보낸 기록은 개발자가 승률 계산식을 더 정확하게 맞추는 데 써요.
