==============================================================
 랭챌 분석기 - 처음 받은 분께
==============================================================

1. 설명서.txt 의 "1. 처음 한 번만 하는 설치" 와 "2. LDPlayer 준비" 를 따라 하세요.
   ★ LDPlayer 해상도는 꼭 900 x 1600 (세로) 이어야 화면을 읽을 수 있어요.

2. 실행.bat 을 더블클릭해서 프로그램을 켭니다.

3. 맨 처음에는 왼쪽 [① 내 덱 읽기] 를 먼저 눌러 내 타자 9명과 선발 5명을 읽게 하세요.
   (이 압축 파일에는 다른 사람의 덱·경기 기록이 들어 있지 않아요. 기록은 쓰면서 새로 쌓여요.)

4. 그다음부터는 랭킹 챌린지 로비 화면에서 [② 상대 분석] → 오른쪽 [추천 배치] 탭 확인 → [③ 결과 기록] 순서로 쓰면 돼요.
   [④ 자동 진행] 은 익숙해진 뒤에, "최대 바퀴 수" 를 1로 두고 한 바퀴만 지켜보면서 시작하세요.

참고
- 실행.bat 으로 켤 때마다 새 버전을 확인해서 자동으로 업데이트돼요. 내 기록과 학습 내용은 그대로 남아요.
- 처음 켤 때 "매주 경기 기록 보내기"를 물어봐요. 상대 닉네임은 지우고 보내고, [설정] 메뉴에서 언제든 끌 수 있어요.
- 숫자·글자 인식용 학습 내용은 미리 들어 있어요. 처음 보는 글자는 위 메뉴 [학습] → [학습 대기 확인] 에서 알려 주면 더 정확해져요.
- [설정] 메뉴의 [클로드 코드 연동] 과 클로드학습.bat 은 Claude Code 를 설치한 사람만 쓰는 선택 기능이에요. 없어도 프로그램은 돌아가요.
- 프로그램이 멈추면 "진단" 폴더에 그때 화면이 저장돼요. 문제를 물어볼 때 그 사진을 같이 보내 주세요.
