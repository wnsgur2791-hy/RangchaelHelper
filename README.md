# 랭챌 분석기 (RangchaelHelper)

컴투스프로야구V26 랭킹챌린지에서 상대 5명의 선발·타자를 자동으로 읽고,
내 선발 5명을 어떤 상대에게 배치하면 기대 승점이 가장 큰지 추천하는 PC 프로그램입니다. (LDPlayer 900×1600 세로)

## 받기
**[전체 받기 (zip)](https://github.com/wnsgur2791-hy/RangchaelHelper/archive/refs/heads/main.zip)**  — 또는 이 페이지 위의 초록색 [Code] → [Download ZIP]

1. zip을 풀면 나오는 `랭챌분석기` 폴더만 원하는 곳으로 옮기고, 그 안의 **처음 읽어주세요.txt** 와 **설명서.txt** 를 따라 설치합니다.
2. `실행.bat` 으로 켭니다.

## 자동 업데이트
`실행.bat` 으로 켤 때마다 이 저장소의 `latest.json`을 확인해서, 새 버전이면 바뀐 파일만 받아 자동으로 바꿉니다.
내 기록(기록데이터, 랭챌기록.xlsx), 설정, 내가 학습시킨 그림은 그대로 남습니다.

## 매주 기록 보내기
처음 켤 때 동의를 받고, 끝난 주의 경기 기록을 상대 닉네임을 지운 채 개발자에게 보냅니다. [설정] 메뉴에서 끌 수 있습니다.

## 폴더
- `랭챌분석기/` 프로그램 (릴리스 zip과 같은 내용)
- `config.json` 프로그램이 읽는 설정 (기록 받는 주소)
- `latest.json` 최신 버전 번호와 파일 목록 (자동 업데이트가 읽음)
- `tools/release.py` 새 버전 배포하기
